Welcome to Parknacross Weather

This is a personal weather station based in Parknacross, near Ardamine in north County Wexford. The site provides live, hyperlocal weather readings from an Ecowitt WS90 and GW3001, including temperature, humidity, wind, rainfall, barometric pressure, solar radiation and UV.

The aim is simple: to give an accurate picture of the weather right here in Parknacross, using data collected from the station throughout the day. This is a personal project rather than an official forecasting service, but it provides a useful real-time view of local conditions and recent weather trends.
