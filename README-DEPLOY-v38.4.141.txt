Parknacross Weather v38.4.141 deployment

This update removes the weather soundscape and all associated audio code and controls. The Ardamine Weather Window illustration and its station readings remain.

1. Download and extract Parknacross-v38.4.141-WEATHER-AUDIO-REMOVED.zip.
2. Upload the website files to the root of the parknacross-weather GitHub repository, replacing matching files. Keep files at the repository root.
3. Commit the changes and wait for GitHub Pages to publish.
4. Refresh the Dashboard. The Weather Window remains, with no Play button or audio controls.

No Cloudflare Worker update is required.
