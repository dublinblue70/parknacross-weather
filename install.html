Installed app

Install Parknacross Weather

Add the live dashboard to your Home Screen for a full-screen app experience, faster return visits and cached pages when the connection is unavailable.

Android · Chrome

Install from Chrome

  1. Open parknacrossweather.ie in Chrome.
  2. Tap the three-dot menu.
  3. Choose Install app or Add to Home screen.
  4. Confirm Install.
Samsung Internet

Add the app

  1. Open the website in Samsung Internet.
  2. Open the browser menu.
  3. Choose Add page to, then Home screen.
  4. Confirm the app name.
iPhone · Safari

Add to Home Screen

  1. Open the website in Safari—not an in-app browser.
  2. Tap the Share button.
  3. Scroll to Add to Home Screen.
  4. Tap Add. Open Parknacross Weather from its new icon.
iPad · Safari

Add to Home Screen

  1. Open the website in Safari.
  2. Tap Share beside the address bar.
  3. Select Add to Home Screen.
  4. Confirm Add.

Update an installed app

When an update banner appears, choose Refresh app. If an old version persists, close the installed app completely and reopen it while online. As a final step, remove the Home Screen app, clear the browser’s website data for parknacrossweather.ie and install it again.

Notifications

Open Station → Weather notifications and choose Enable notifications. iPhone and iPad notifications require the site to be installed on the Home Screen. These are local station alerts, not official Met Éireann warnings.

Offline use

Previously opened pages and the latest saved information may remain available offline. Always check the displayed observation time: cached information is not a live weather reading.

Still having trouble?

Open the App installation diagnostics on the Station page. It reports installation mode, service-worker status, notification capability, platform and network state.
