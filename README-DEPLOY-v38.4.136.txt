PARKNACROSS WEATHER v38.4.136 PATCH

3. Commit/publish the changes and allow GitHub Pages to finish deploying.

Also delete the retired or duplicate files listed in DELETE-FROM-GITHUB-v38.4.134.txt if they are still present in the GitHub repository root.
