Weather Lab clarity update

- Every coastal timeline entry now displays an explicit Irish-local date and time.

- Removed Forecast Accountability.
- Removed Recent Weather Stories.
- Removed Visual Weather Diary.
- Removed Microclimate Explorer.
- Removed Open Local Weather.
- Removed the deleted sections' JavaScript, network requests and unused styles.
- Added regression checks to prevent the removed sections from returning accidentally.

Existing weather observations, calculations, charts, navigation and archive logic are unchanged.
