PARKNACROSS WEATHER — WEBSITE DEPLOYMENT

1. Extract this release ZIP.
2. Upload the complete contents of parknacross-weather-main to the root of the
   GitHub Pages repository, preserving filenames and folders.
3. Remove obsolete backend copies from GitHub if they exist: worker.js,
   cloudflare-worker.js, worker-v*.js and Parknacross-worker-*.txt.
4. Do not change the separately deployed Cloudflare Worker.
5. Commit the website files and wait for GitHub Pages to finish deploying.
6. Open parknacrossweather.ie/status.html and confirm the website, API and live
   observation checks complete.
7. Open the More menu on Android and iPhone/Safari and confirm it opens, scrolls
   and closes with Escape or a tap outside.
8. If an installed PWA shows an older release, close and reopen it once so the
   new browser service-worker cache can activate.

Important: service-worker.js is the website's offline/PWA cache worker. It is
not the Cloudflare API Worker and should remain in GitHub.
